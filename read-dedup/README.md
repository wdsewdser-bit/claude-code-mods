# read-dedup

重复 Read 去重：模型再次读取一个仍在上下文里的文件时，未变化就只返回一行提示，变化了只返回差异，省掉重复的文件内容。

- 只有当前对话（Messages API 形态）里确实还留着之前那次 Read 的结果时才去重；压缩、`/clear`、ctx-mod 换窗口之后会照常返回全文。
- 模型自己 Edit / Write 过的文件，下一次 Read 返回差异而不是提示。
- 主会话里单条的 Bash 纯读取（`cat 文件`、`sed -n 'a,bp' 文件`、`head -n N 文件`，可以带开头的 `cd 目录 &&`）与 Read 共用同一份记录：范围完全相同且文件未改时返回提示；带管道、重定向、多个文件、变量或 glob 的命令一律照常执行；不足 300 字符的读取不替换。
- 主会话和每个子代理分开记录。
- 缓存只在内存里，热加载后清空，最多多读一次全文。
